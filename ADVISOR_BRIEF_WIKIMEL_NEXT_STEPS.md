# Advisor Brief: WikiMEL Quantization Plan (Ready for Execution)

## Goal

Run publication-grade quantization experiments for multimodal entity linking on a proper WikiMEL-style benchmark, using the existing repository benchmarks with a strict and reproducible protocol.

## What was added today

1. `prepare_wikimel_artifacts.py`

- Builds benchmark artifacts from your official dataset files.
- Outputs the exact artifact format consumed by the existing benchmark scripts.
- Encodes query images, paired query texts, and full KB entity texts with OpenCLIP.
- Produces:
  - `entity_kb.json`
  - `embeddings/valid_metadata.json`
  - `embeddings/image_embeddings.npy`
  - `embeddings/text_embeddings.npy`
  - `embeddings/kb_text_embeddings.npy`
  - `embeddings/query_to_entity.json`
  - `benchmark_spec.json`

1. `run_wikimel_suite.py`

- Runs the full benchmark stack end-to-end on prepared artifacts:
  - embedding quantization benchmark
  - encoder quantization benchmark
  - FAISS/PQ index quantization benchmark
- Saves all results under one output directory.

## One-command workflow (after dataset paths are known)

### 1) Prepare WikiMEL artifacts

```powershell
python prepare_wikimel_artifacts.py `
  --queries <PATH_TO_WIKIMEL_QUERIES_JSON_OR_JSONL> `
  --entities <PATH_TO_WIKIMEL_ENTITIES_JSON_OR_JSONL> `
  --dataset-root <OPTIONAL_DATASET_ROOT> `
  --out-dir data/wikimel_v1
```

If your field names differ from defaults, map them explicitly:

```powershell
python prepare_wikimel_artifacts.py `
  --queries <...> `
  --entities <...> `
  --query-id-field <...> `
  --query-entity-id-field <...> `
  --query-image-field <...> `
  --query-text-field <...> `
  --entity-id-field <...> `
  --entity-title-field <...> `
  --entity-description-field <...>
```

### 2) Run full benchmark suite

```powershell
python run_wikimel_suite.py `
  --artifact-root data/wikimel_v1 `
  --out-dir benchmarks/wikimel_v1 `
  --quant-modes fp32 fp16 int8 `
  --repeats 5 `
  --warmup 1
```

## Suggested paper-grade protocol

1. Fix split and candidate policy before running ablations.
2. Keep candidate KB constant across all quantization conditions.
3. Use same hardware/software stack for all comparisons.
4. Repeat timed runs and report mean/std.
5. Report both effectiveness and systems metrics.

## Risk checklist (to avoid reviewer pushback)

1. Verify one-to-one query-to-gold entity mapping.
2. Verify no missing entities in KB for evaluation queries.
3. Verify image decode failures are logged and counted.
4. Verify no split leakage in pre-processing.
5. Verify all quantization runs use identical query set.
